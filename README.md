# Marstek Monitor

Windows x64 application for monitoring Marstek battery telemetry, backup history and outage schedules.

Download the latest installer from [Releases](https://github.com/bystranovskiy/marstek-monitor-releases/releases/latest).
From version 3.8.0, the app checks for updates automatically and offers installation in Settings → About.
Update packages are verified with the application's signing key. No GitHub account is required.

Existing archives, settings and saved Cloud credentials remain on the PC during updates.
The application source and build workflow are maintained in a private repository.

This repository contains distribution files only. It does not contain application source, account credentials or private station data.
